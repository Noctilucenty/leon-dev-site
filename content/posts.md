# Posts, ready to publish

Every line here is written natively in its language, not translated. Rules applied
throughout: no city or region named anywhere, no testimonial or client name, no
rating, no download count, no "trusted by N businesses". Prices are the published
floors and nothing else. Contact is WhatsApp for English/Portuguese/Spanish and
WeChat for Chinese, because a Chinese owner in the US does not use WhatsApp.

Links carry `?s=` so the traffic dashboard can tell these apart. Do not strip it.

## What each `?s=` tag means

| tag | where it was posted |
|---|---|
| `fbmkt-en` / `fbmkt-pt` / `fbmkt-es` / `fbmkt-zh` | Facebook Marketplace listing, that language |
| `fbgrp-en` / `fbgrp-pt` / `fbgrp-es` / `fbgrp-zh` | Facebook group post, that language |
| `wa-fwd` | forwarded into a WhatsApp group by someone else |
| `wechat` | sent in WeChat |
| `client-ref` | forwarded by a past client |

Read them at `https://leon-assist.onrender.com/api/traffic?key=<LEADS_KEY>` — the key is
in the Render dashboard under the leon-assist service, Environment tab. That file resets
on every deploy, so snapshot it before pushing anything.
